## Password-reset MVP acceptance gate

1. Password-reset meaning is understandable from Orin artifacts without reading
   generated code.
2. Unresolved consequential ambiguity is surfaced and blocks compile/readiness.
3. Conformance examples run deterministically.
4. Implementation variation does not change required observable behavior.
